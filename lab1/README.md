# Лабораторная работа 1

## Поиск по каталогу аэропортов

## Вариант

```text
airports-csv | title | fold | words-all | best | plain | none
```

## Что делает программа

Программа загружает данные об аэропортах из CSV-файла и работает в консоли. Можно искать аэропорты по названию, добавлять фильтры, показывать записи и сохранять последнюю выдачу в текстовый файл.

Данные находятся в файле `data/airports/records.csv`. В нём 8000 записей.

## Запуск

В PyCharm нужно открыть `main.py` и нажать Run.

Из терминала в папке `lab1`:

```bash
python main.py
```

После запуска сначала нужно загрузить данные:

```text
load records.csv
```

## Объяснение варианта

- `airports-csv` - данные об аэропортах находятся в CSV-файле
- `title` - поиск выполняется только по полю `title`, то есть по названию аэропорта
- `fold` - регистр букв не учитывается
- `words-all` - все слова запроса должны быть среди слов названия аэропорта
- `best` - программа находит все подходящие записи, но показывает только одну лучшую
- `plain` - совпадения не выделяются
- `none` - у записей нет оценок, поэтому команд `rate` и `ratings` нет

## Команды

| Команда | Что делает |
| --- | --- |
| `help` | Показывает список команд |
| `load <файл>` | Загружает CSV и сбрасывает фильтры и последнюю выдачу |
| `show` | Показывает все загруженные записи без фильтров |
| `fields` | Показывает поля, их типы и допустимые фильтры |
| `filter add <поле> <оператор> <значение>` | Добавляет фильтр |
| `filter list` | Показывает добавленные фильтры |
| `filter remove <номер>` | Удаляет один фильтр |
| `filter clear` | Удаляет все фильтры |
| `search "<запрос>"` | Выполняет поиск |
| `save <файл>` | Сохраняет последнюю выдачу |
| `exit` | Завершает программу |

До загрузки данных работают только команды `help`, `load` и `exit`.

Если указать файл не с расширением `.csv`, программа выводит понятную ошибку и продолжает работу.

## Загрузка данных

Программа использует `csv.DictReader`. Каждая строка CSV-файла становится словарём. Например, название аэропорта можно получить так:

```python
record["title"]
```

Числовые поля `elevation_ft`, `latitude`, `longitude` преобразуются в `float`. Поле `scheduled` преобразуется в `True`, `False` или `None`, если значение отсутствует.

## Поиск

Поиск выполняется только в поле `title`.

Перед сравнением запрос и название приводятся к одному регистру с помощью `casefold()`. Затем `split()` разбивает их на слова.

Например, запрос:

```text
search "LOGAN boston"
```

найдёт аэропорт `Boston Logan International Airport`, потому что регистр и порядок слов не важны.

Режим `words-all` означает, что каждое слово из запроса должно быть в названии. Если хотя бы одного слова нет, запись не подходит.

Релевантность вычисляется по формуле:

```text
число слов в запросе / число слов в названии
```

При одинаковом запросе запись с более коротким названием получает большую релевантность. В режиме `best` программа запоминает и показывает только запись с наибольшей релевантностью.

## Фильтры

Строковые поля:

```text
country, kind
```

Операторы для них:

```text
eq, ne, contains
```

Числовые поля:

```text
elevation_ft, latitude, longitude
```

Операторы для них:

```text
eq, ne, lt, le, gt, ge
```

Логическое поле:

```text
scheduled
```

Операторы для него:

```text
eq, ne
```

Примеры:

```text
filter add country eq US
filter add scheduled eq true
filter add elevation_ft gt 1000
```

Все добавленные фильтры применяются одновременно. Пустое поле не проходит фильтр.
